# 中文写入模板

给人看的页面必须用中文表达。只保留业务里已经约定俗成的缩写或名词，例如 SKU、ASIN、ACOS、CVR、CPC、FBA、listing、Buy Box、SP、SB、SBV。

禁用半中半英写法：

- 不写 `live read`，写“实时读取”。
- 不写 `readback`，写“读回验证”。
- 不写 `lane`，写“流量”。
- 不写 `campaign / ad group / keyword / target`，写“广告活动、广告组、关键词、投放目标”。
- 不写 `playbook`，写“标准打法”。
- 不写 `dry-run`，写“预演”。

```text
结论：
日期：
证据：
为什么这样判断：
适用边界：
是否需要实时读取：
下次复查：
```

如果不是实时读取得出的证据，要明确写清楚来源和可能过期。
