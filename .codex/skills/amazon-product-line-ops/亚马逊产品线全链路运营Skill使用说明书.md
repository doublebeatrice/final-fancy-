# 亚马逊产品线全链路运营 Skill 使用说明书

本说明书是给你日常使用 `amazon-product-line-ops` 技能时看的。它告诉你：什么时候用这个 skill、应该给我什么资料、资料不完整时怎么处理、我会按什么流程分析、最后会输出什么结果。

## 一、这个 Skill 能帮你做什么

这个 skill 是一个“亚马逊产品线全链路运营助手”，不是单纯的资料总结工具。它适合处理从选品到上架、从词库到广告、从日常数据到复盘决策的一整套问题。

你可以用它做：

1. 产品机会判断：这个产品能不能做，应该怎么切入。
2. 产品画像梳理：产品是什么，卖给谁，解决什么问题，差异点是什么。
3. 市场与节点分析：这个关键词背后到底是什么市场、什么商品集、什么价格带。
4. 竞品分析：先判断标品、非标品、半标品，再筛选真正相似竞品。
5. 卖家精灵数据整理：你下载表格后，我做字段识别、清洗、归类、人工确认表。
6. 词库搭建和检查：把关键词分成页面词、广告词、PT 目标、否词、待确认词。
7. Listing 检查：标题、五点、A+、后台词是否承接产品事实和关键词。
8. 主图、附图、A+、视频、包装、说明书一致性检查。
9. 定价、coupon、毛利、预算、库存、现金联动测算。
10. PPC 广告架构：Auto、Broad、Phrase、Exact、PT、防守、探索、收割怎么分。
11. 广告优化诊断：ACOS 高时，不只看 ACOS，还看 CTR、CVR、CPC、CPA、TACOS、coupon、库存、现金、Review、自然流量。
12. Day 0-D90 上线经营：上线后每个阶段看什么数据、怎么调。
13. 周会复盘：把数据变成动作，而不是只报表。
14. Go / Fix / Hold / Pivot / Kill 决策：继续、修复、暂停、转向还是停止。
15. 政策更新和时间线维护：以后 Amazon 政策变化时，判断哪些内容要保留、修改、新增、删除或待查。

## 二、怎么调用这个 Skill

你可以直接在对话里说：

```text
使用 amazon-product-line-ops 帮我分析这个产品。
```

也可以更自然地说：

```text
帮我看一下这个亚马逊产品能不能做。
我给你卖家精灵数据，你帮我整理竞品和关键词。
我给你广告报表，帮我看为什么 ACOS 高。
我给你关键词，你按这套系统帮我搜索和梳理市场。
我把所有资料都发给你，你先帮我盘点，再告诉我还缺什么。
```

如果当前 Codex 环境能使用这个 skill，它会自动读取技能里的流程和参考文件。若技能列表没有刷新，可以新开一个线程或明确说 `使用 amazon-product-line-ops`。

## 三、最省事的使用方式

你不需要一开始把所有表格都填完整。最省事的方式是：

```text
我给你：
1. 产品图片或产品链接
2. 目标站点，例如美国站
3. 卖家精灵导出的竞品/关键词/CPC 数据
4. 产品成本和目标售价，如果有
5. 广告报表，如果已经上线

你先帮我盘点资料，再告诉我哪些能直接分析，哪些需要人工确认。
```

我会先输出：

1. 收到哪些资料。
2. 每份资料属于产品、市场、竞品、关键词、广告、成本、库存、Review/VOC、Listing、合规中的哪一类。
3. 识别出哪些字段。
4. 哪些数据可直接用。
5. 哪些数据需要你人工确认。
6. 还缺哪些关键数据。
7. 初步产品判断和下一步动作。

## 四、最低需要给我的资料

如果你只想让我先做初步判断，最低给这些就可以。

| 资料 | 必要程度 | 说明 |
|---|---|---|
| 产品图片或链接 | 必填 | 用来判断产品形态、标品/非标品、竞品相似度 |
| 目标站点 | 必填 | 例如 US、UK、DE、JP，不同站点价格、政策、搜索习惯不同 |
| 产品名称/一句话描述 | 必填 | 说明它到底是什么，不要只写大类 |
| 目标售价或价格带 | 建议提供 | 用来判断价格带和毛利空间 |
| 产品成本 | 建议提供 | 没有成本只能做市场判断，不能做真实利润判断 |
| 核心关键词 | 建议提供 | 用来判断搜索入口和商品集 |
| 竞品 ASIN | 建议提供 | 没有 ASIN 也可以先用关键词和图片推断 |
| 卖家精灵导出数据 | 建议提供 | 可大幅减少手填 |

如果这些都没有，也可以先聊方向，但我只能给低置信判断，不能直接给 Go/No-Go。

## 五、推荐你提供的完整数据包

如果你想让我做完整产品全案，推荐准备下面这些资料。

### 1. 产品基础资料

| 字段 | 示例 | 用途 |
|---|---|---|
| 产品名称 | silicone kitchen mat | 判断产品身份 |
| 站点 | Amazon US | 判断价格、语言、规则 |
| 产品图片 | 主图、细节图、包装图 | 判断形态、材质、组件、非标品相似度 |
| 产品链接 | Amazon 链接或供应商链接 | 读取页面和产品事实 |
| 规格参数 | 尺寸、容量、数量、型号、兼容 | 判断标品、半标品、页面承接 |
| 材质/颜色/款式 | 硅胶、黑色、2 pack | 判断关键词和竞品 |
| 使用场景 | 厨房、露营、宠物、车载 | 判断场景词和用户画像 |
| 目标用户 | 家庭用户、专业用户、送礼人群 | 判断文案和广告方向 |
| 产品成本 | 出厂价、包装、头程 | 计算毛利和广告边界 |
| MOQ/交期 | 1000 pcs，30 天 | 判断供应链和现金 |
| 认证/合规 | FDA、CPC、CE、专利等 | 判断风险 |

### 2. 市场与关键词数据

优先给卖家精灵导出表。如果没有，给截图或关键词列表也可以。

| 数据 | 关键字段 | 用途 |
|---|---|---|
| 关键词挖掘 | keyword、搜索量、趋势、CPC、竞争度 | 判断搜索入口 |
| ASIN 反查词 | ASIN、keyword、自然排名、广告排名 | 看竞品真实流量词 |
| ABA/SFR 数据 | keyword、排名、份额 | 判断大词和长尾词 |
| CPC 数据 | keyword、建议竞价、竞争程度 | 判断广告成本 |
| 趋势数据 | 月度变化、季节性 | 判断是否季节品 |

我会把关键词分成：

1. 标题核心词。
2. 五点/属性词。
3. A+/场景词。
4. 痛点词。
5. 广告探索词。
6. Exact 攻击词。
7. ASIN/PT 目标。
8. 否词池。
9. 人工待确认词。

### 3. 竞品数据

卖家精灵、Amazon 页面、截图或你整理的 ASIN 表都可以。

| 字段 | 用途 |
|---|---|
| ASIN | 竞品 ID |
| 标题 | 判断产品身份和关键词 |
| 品牌 | 判断品牌壁垒 |
| 主图/图片 | 非标品竞品相似度判断 |
| 价格/sale price/coupon | 判断价格带和到手价 |
| Review 数/评分 | 判断信任壁垒 |
| 月销量/月销售额估算 | 判断市场结构 |
| BSR/类目 | 判断类目位置 |
| 变体数量 | 避免重复放大市场 |
| 上架时间 | 判断新品机会 |
| 页面弱点 | 主图、附图、A+、FAQ、包装 |
| 差评痛点 | 产品改进和页面机会 |

我会先判断你的产品是：

1. 标品：优先看参数、型号、规格、兼容、认证、用途。
2. 非标品：优先看图片、形态、风格、材质、场景、人群。
3. 半标品：参数和视觉都要看。

然后把竞品分成：

1. 直接竞品。
2. 替代竞品。
3. 学习竞品。
4. 广告竞品。
5. 避让竞品。
6. 剔除样本。

### 4. Listing 和视觉资料

如果你已经有 Listing 草稿，可以给：

| 资料 | 用途 |
|---|---|
| 标题 | 检查关键词、产品身份、合规风险 |
| 五点 | 检查结果、机制、场景、规格、信任 |
| A+ 文案 | 检查教育、对比、品牌叙事 |
| 后台 Search Terms | 检查重复、无关词、品牌词风险 |
| 主图 | 检查移动端识别度、差异性、合规 |
| 附图 | 检查规格、场景、使用步骤、对比 |
| 视频脚本 | 检查是否承接用户顾虑 |
| 包装图 | 检查页面承诺和实物一致性 |
| 说明书 | 检查误用、退货和差评风险 |

我会检查：

1. 页面是否承接核心关键词。
2. 文案是否承接产品事实。
3. 主图是否能在移动端一眼看懂。
4. 附图是否解释规格、场景、使用步骤、到手组件。
5. A+ 是否解决用户为什么买、怎么选、怎么用。
6. 包装和说明书是否降低误用和差评。
7. 是否存在夸大、侵权、医疗/安全/绝对化表达等风险。

### 5. 成本、定价、coupon、库存和现金数据

这是判断“能不能放量”的关键。

| 字段 | 用途 |
|---|---|
| 产品成本 | 计算贡献毛利 |
| 包装成本 | 计算真实成本 |
| 头程 | 计算到仓成本 |
| FBA 费用 | 计算平台成本 |
| Amazon 佣金 | 计算毛利 |
| 目标 sale price | 判断价格带 |
| coupon 面额 | 判断到手价和利润 |
| 退货率预估 | 判断真实利润 |
| 首批库存 | 判断可售天数 |
| 补货周期 | 判断断货风险 |
| 可用现金 | 判断广告和补货能否同时承接 |

我会重点算：

1. 广告前贡献毛利。
2. Breakeven CPA。
3. Breakeven CPC。
4. coupon 后毛利。
5. 库存灯：绿、黄、红。
6. 现金灯：绿、黄、红。

### 6. 广告数据

如果产品已经上线，请尽量提供 Amazon Ads 导出。

| 报表 | 关键字段 | 用途 |
|---|---|---|
| Campaign 报表 | campaign、budget、spend、sales、ACOS | 看预算池和整体结构 |
| Targeting 报表 | keyword/ASIN、match、bid、CTR、CVR、ACOS | 看目标表现 |
| Search Term 报表 | customer search term、clicks、spend、orders、sales | 做迁移、否词、隔离 |
| Placement 报表 | Top of Search、Product Pages、Rest of Search | 看 placement 加价风险 |
| Advertised Product 报表 | SKU/ASIN、花费、销售、订单 | 看 SKU 承接 |
| Business Reports | Sessions、Unit Session % | 看页面转化 |
| SQP/ABA | 查询、自然点击、自然购买 | 看自然流量回流 |

广告诊断时，我不会只看 ACOS。我会同时看：

1. 数据置信度：样本量、归因窗口、是否刚改价格/页面/bid。
2. 流量相关性：搜索词、ASIN、属性、场景是否匹配。
3. CTR：主图、标题、价格、coupon、Review 是否吸引点击。
4. CVR：页面、A+、FAQ、价格、Review 是否能转化。
5. CPC：战场是否太贵，bid/placement 是否失控。
6. CPA：是否超过 Breakeven CPA。
7. TACOS：广告是否带动整体自然增长。
8. coupon：领取率、核销率、毛利是否合理。
9. 库存/现金：是否允许继续放量。
10. Review/退货：广告是否带来长期风险。

## 六、如果你只给关键词，我会怎么做

你可以这样给：

```text
关键词：portable blender
站点：美国站
目标：帮我判断这个方向能不能做，并整理商品集、竞品和关键词。
```

如果当前环境有 MCP、浏览器或搜索工具，我会：

1. 确认关键词和站点。
2. 拆搜索意图：品类词、属性词、场景词、痛点词、人群词。
3. 建立商品集假设：主产品、配件、替换件、套装、补充装是否混在一起。
4. 搜索/采样竞品。
5. 清洗 ASIN 池。
6. 判断标品、非标品、半标品。
7. 筛选直接竞品、替代竞品、学习竞品、避让竞品。
8. 整理关键词初稿和否词池。
9. 观察价格、coupon、Review、广告位、页面弱点。
10. 输出结构性低效、机会、风险和下一步采集计划。

如果当前环境没有 MCP 或搜索工具，我会明确告诉你无法直接查，然后让你提供卖家精灵导出、Amazon 截图、链接或 ASIN 列表。不会假装已经检索。

## 七、如果你直接丢一堆资料给我

你可以把产品图、Excel、CSV、PDF、截图、广告报表、卖家精灵数据一起发来。

我会先做“数据盘点”，不是马上下结论。

输出格式一般是：

```text
1. 文件清单
2. 每份文件的类型判断
3. 可识别字段
4. 数据日期和站点
5. 可直接分析的数据
6. 需要人工确认的数据
7. 暂不能使用的数据
8. 还缺的数据
9. 初步判断
10. 下一步动作
```

这样做的目的是减少你手工整理时间。你只要把资料给我，我先帮你把资料归位。

## 八、我最终可以输出什么

根据你给的数据完整度，我可以输出不同深度的结果。

### 1. 初步诊断

适合数据少的时候。

输出：

1. 产品初判。
2. 标品/非标品判断。
3. 可能竞品和关键词方向。
4. 主要风险。
5. 缺失数据。
6. 暂定结论：低置信 Go / Validate / Hold / No-Go。

### 2. 产品全案

适合你给了产品图、卖家精灵数据、竞品、关键词、成本。

输出：

1. 产品画像。
2. 市场与节点判断。
3. 竞品与结构性低效。
4. VOC/Review 与用户画像。
5. 产品定义与 SKU 角色。
6. 定价、coupon、毛利、库存、现金。
7. Listing、主图、附图、A+、包装建议。
8. 词库结构和页面/广告/否词路由。
9. 广告架构和上线节奏。
10. Day 0-D90 指标与复盘机制。
11. 风险红线与政策待查项。
12. Go / Validate / Hold / Pivot / No-Go。
13. 下一步行动清单。

### 3. 广告优化诊断

适合已经上线、有广告报表的时候。

输出：

1. 当前广告阶段。
2. 数据置信度。
3. ACOS 高的真实原因分解。
4. campaign 结构问题。
5. 搜索词动作：保留、迁移、降 bid、否定、隔离。
6. 页面、价格、coupon 修复建议。
7. 下周广告动作。
8. 风险和回滚条件。

### 4. 周度经营复盘

适合每周复盘。

输出：

1. 本周销售、广告、自然、毛利概览。
2. CTR/CVR/CPC/CPA/ACOS/TACOS 联动诊断。
3. 价格/coupon 是否有效。
4. Review/VOC/退货问题。
5. 库存和现金灯。
6. 竞品变化。
7. 上周动作结果。
8. 下周动作、负责人、观察窗口、成功指标、回滚条件。

## 十一、我需要你人工确认的内容

即使我能自动整理数据，以下内容最好由你确认：

1. 产品图片判断是否准确。
2. 产品是标品、非标品还是半标品。
3. 哪些竞品是真正相似竞品。
4. 哪些 ASIN 只是替代品、学习对象或应该剔除。
5. 哪些关键词产品真实能承接。
6. 哪些关键词绝对不能投或不能写进 Listing。
7. 产品成本、FBA、佣金、头程、coupon 是否准确。
8. 认证、专利、商标、类目限制是否存在。
9. 库存、补货和现金是否允许放量。
10. 是否有你不想碰的价格带、人群、渠道或风险。

## 十二、重要注意事项

1. 卖家精灵数据是线索，不是最终结论。
2. 高销量 ASIN 不一定是直接竞品。
3. 同一个关键词下可能混有多个商品集。
4. 非标品不能只按关键词和销量选竞品。
5. 标品不能只看图片相似，必须核对规格、参数、兼容、认证。
6. ACOS 高不能直接砍广告，要看 CTR、CVR、CPC、CPA、TACOS、coupon、库存、现金。
7. coupon 领取高不等于有效，还要看核销率、CVR 和毛利。
8. 库存或现金红灯时，不要盲目放大广告。
9. 页面承诺、包装、说明书、广告词必须一致。
10. Amazon 政策、费用、广告功能、促销资格、Review/Vine 规则会变化，真实执行前要核对当前后台或官方规则。

## 十三、一次完整协作的推荐流程

```text
第 1 步：你给产品图/关键词/卖家精灵数据
第 2 步：我做数据盘点和字段识别
第 3 步：我判断标品/非标品，并筛竞品
第 4 步：你确认竞品和产品事实
第 5 步：我做市场、词库、VOC、产品定义
第 6 步：你补成本、库存、现金、合规信息
第 7 步：我做定价、Listing、广告和上架计划
第 8 步：上线后你给广告和经营数据
第 9 步：我做 Day 0-D90 诊断和周会复盘
第 10 步：我们决定 Go / Fix / Hold / Pivot / Kill
```

## 十四、什么时候结论不能太满

如果出现下面情况，我会降低结论置信度：

1. 没有目标站点。
2. 没有产品图片或规格。
3. 没有成本和 FBA 费用。
4. 没有竞品 ASIN 或竞品数据。
5. 广告样本太少。
6. 数据还在归因窗口。
7. 最近同时改了价格、coupon、主图、Listing、bid。
8. 卖家精灵数据、广告数据、后台数据日期不一致。
9. 类目涉及强合规或政策风险，但没有官方确认。

这种情况下，我会输出“低置信/中置信暂定判断”，并告诉你补哪些数据后才能进入强结论。

## 十五、最推荐你以后怎么用

最推荐的方式不是先填一大堆模板，而是：

```text
我先把产品图、卖家精灵数据、关键词、竞品和广告数据都发给你。
你先按 amazon-product-line-ops 做数据盘点和人工确认表。
确认完以后，再继续做产品全案、上架计划和广告优化。
```

这样最省时间，也最接近真实运营流程。
