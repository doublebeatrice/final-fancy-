# 术语与风险边界

当用户需要术语解释、概念辨析、初学者教学或合规风险提醒时，读取本文件。

## 核心概念辨析

| 概念 | 是什么 | 不是什么 |
|---|---|---|
| 产品线方向 | 用户、问题、能力、边界和排除项 | 一个热卖产品名 |
| 市场 | 带国家、价格、人群、场景和竞争的需求空间 | 一个关键词 |
| 节点 | 需求 + 产品形态 + 竞争 + 价格带 + 可运营空间 | 关键词或 ASIN |
| 商品集 | 用户任务、机制、形态和搜索意图接近的一组产品 | 整个大类目 |
| SKU 角色 | 一个 SKU 在流量、利润、升级、防守、复购、现金中的任务 | 随机变体 |
| 词库 | 带相关性、意图、路由和动作的搜索资产 | 搜索量列表 |
| 竞品库 | 攻击、学习、避让和动作地图 | 截图收藏夹 |
| VOC | 用户语言到产品/页面/运营动作的翻译 | 好评摘录 |
| 产品定义 | 内部工程图和经营输入 | 对外卖点 |
| 广告 | 流量验证和预算分配 | 补救弱产品/弱页面的工具 |
| 周会 | 带动作、负责人和复查的决策系统 | 报数会议 |

## 常见错误

- 市场和节点门控没过，就开始找供应商。
- 把大词当成产品机会。
- 词库没有页面/广告/否词路由。
- 把竞品品牌词写进 Listing 或后台 search terms。
- 用“高级、耐用、简单”代替可测产品事实。
- 让设计凭感觉做图，而不是从产品定义和 VOC 出发。
- coupon 按习惯设置，不看毛利、CVR、CPA 和风险。
- 库存或现金红灯时继续放大广告。
- 未诊断 setup、target、page、price、inventory 就 kill 产品。
- 产品线角色和现金没验证就扩 SKU。

## 术语表

| 术语 | 工作定义 |
|---|---|
| 方向卡 | 一页写清目标用户、问题、能力、边界和不做清单 |
| 市场雷达 | 从需求、流量、竞争、内容、广告、资金六维看市场 |
| 结构性低效 | 竞品在内容、视觉、教育、产品、定价、广告、包装或路径中的系统弱点 |
| ASIN 池 | 原始 ASIN 证据集合，必须先去重和分类再下结论 |
| 产品 Brief | 从商品集证据到产品定义、RFQ、文案、视觉和广告的桥 |
| RFQ | 验证供应商能否实现产品定义，不只是询价 |
| 5D 词库 | 带价值、相关性、意图/类型、路由、时间/阶段价值的词库 |
| 否词路由 | 决定排除、隔离、观察或继续测试哪些词/ASIN |
| Breakeven CPA | 不亏损时每单可承受的广告获客成本 |
| Breakeven CPC | 根据 CPA 容忍和 CVR 反推的点击成本上限 |
| G-M-R | 手册中的分层广告架构概念；本地团队可按探索/迁移/收割或目标/市场/响应等口径命名，若涉及内部定义需向用户确认 |
| SQP | Search Query Performance 或类似查询层级信号；适合看自然查询洞察，不替代广告报表 |
| RACI | Responsible 负责、Accountable 最终负责、Consulted 咨询、Informed 知情 |
| Go/pivot/kill | 基于证据的继续、转向或停止决策 |

## 风险边界

亚马逊规则、工具、报表、费用和资格条件会变化。真实执行前必须核对当前 Seller Central / Amazon Ads 政策：

- Review 请求、激励、买家沟通、评论操纵边界。
- Vine 资格、报名、限制、费用和评论展示。
- coupon、Prime Exclusive Discount、Lightning Deal、Best Deal、价格历史要求。
- 商品详情页规则、标题规则、五点限制、search terms、变体政策。
- 主图、附图、A+、视频、包装和功效宣称要求。
- 广告产品、匹配方式、placement、归因窗口、报表、竞价选项、受众控制。
- Brand Registry、Brand Store、Posts/Creator/influencer 内容和品牌分析可用性。
- FBA 费用、佣金、仓储、入仓配置、低库存、退货、移除、赔偿规则。
- 受限商品、合规文件、认证、安全、医疗/健康、儿童、食品接触、美妆、农药、电子、电池。
- 各站点税务、标签、回收、EPR、GPSR、清关和进口要求。

不确定时，明确说：`不确定，需要进一步查证，以 Seller Central / Amazon Ads 当前后台规则为准。`

## 安全合规姿态

- 不承诺 Review、评分、排名、销量或平台结果。
- 不建议评论操纵或站外激励。
- 不在文案、A+、图片、包装或广告中使用未验证宣称。
- 未确认政策和法律依据前，不把竞品品牌词写入 Listing 或后台词。
- 不把手册当作当前平台规则的替代品。
- 保留宣称、认证、供应商文件、图片授权和测试报告证据。
