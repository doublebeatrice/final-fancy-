# 指标与诊断

当用户询问定价、coupon、广告、上线优化、周会复盘、Go/pivot/kill 诊断时，读取本文件。

## 核心指标

| 指标 | 公式 | 用途 |
|---|---|---|
| CTR | 点击 / 曝光 | 判断搜索结果页吸引力：主图、标题、价格、coupon、Review |
| CVR | 订单 / 点击 | 判断详情页和 offer 转化 |
| CPC | 广告花费 / 点击 | 判断流量成本 |
| CPA | 广告花费 / 订单 | 判断单个订单获客成本 |
| ACOS | 广告花费 / 广告销售额 | 判断广告销售效率 |
| TACOS | 广告花费 / 总销售额 | 判断广告对整体经营的压力 |
| ROAS | 广告销售额 / 广告花费 | 判断每 1 美元广告费带来的销售额 |
| coupon 核销率 | 核销 coupon 数 / 领取 coupon 数 | 判断优惠兴趣是否转成购买 |
| 广告前贡献毛利 | 到手收入 - 产品/平台/FBA/头程/coupon/变动成本 | 判断广告和利润空间 |
| Breakeven CPA | 约等于广告前贡献毛利 | 不亏损时每单最多能花多少广告费 |
| Breakeven CPC | Breakeven CPA × 预期 CVR | 不亏损时每次点击最多能花多少钱 |

公式必须根据具体站点、佣金、FBA 费用、coupon 规则、退货率和当前费用表校准。

## 定价与 coupon 逻辑

把价格当作可测试区间，不要当作固定设置。

检查：

- sale price
- coupon 面额
- 用户实际到手价
- coupon 领取率
- coupon 核销率
- CVR
- CPA
- 毛利与贡献毛利
- Review/退货风险
- 库存和补货现金

解释示例：

- coupon 领取高、核销低：优惠吸引了用户，但页面、信任、价格、规格、Review 或产品匹配没有完成转化。
- CVR 上升但毛利为负：转化改善了，但模型未必能放量。
- CPA 可接受但库存红灯：不要继续放大广告，先处理库存/现金门控。
- 同一天改价格又改 bid：无法判断变化来自价格、广告还是页面。

## Day 0-D90 诊断窗口

| 阶段 | 核心问题 | 重点观察 | 避免 |
|---|---|---|---|
| D0-D7 | 设置是否正确，流量是否相关 | Listing 状态、价格/coupon、库存、广告投放、CTR、CPC、搜索词相关性 | 用当天 ACOS 恐慌决策 |
| D8-D30 | 页面和 offer 能否转化 | CVR、CPA、coupon 核销、Review/Q&A、主图/A+反馈 | 页面信任没修就放量 |
| D31-D60 | 模型能否扩大 | TACOS、自然单、SQP/自然词信号、排名、库存、现金 | 广告增长导致断货或现金紧张 |
| D61-D90 | 能否防守和扩展 | 核心词/ASIN 防守、coupon 退坡、LD/BD、Store 路径、关联 SKU 证据 | 没有产品线逻辑就扩 SKU |

## 漏斗诊断

| 症状 | 先诊断 | 可能动作 |
|---|---|---|
| 曝光低 | 索引、bid/budget、定向、价格竞争力、campaign 状态 | 修 setup、调 bid/budget、谨慎扩大测试 |
| 曝光好但 CTR 低 | 主图、标题、价格、coupon、Review、相关性 | 改主图/标题/offer，清理弱定向 |
| 点击好但 CVR 低 | 页面信任、规格清晰度、价格、Review、A+、匹配度 | 修五点、图片、A+、FAQ、价格/coupon、产品边界 |
| CPC 高 | 战场竞争、placement/bid 叠加、定向过宽 | 转长尾/PT、控制 bid、检查 placement |
| CPA 高 | CPC 太高或 CVR 太低 | 同时诊断流量成本和页面转化 |
| ACOS 高但自然增长好 | 可能是启动期投入 | 看 TACOS、毛利、阶段目标和现金 |
| coupon 强但销售弱 | 有兴趣但不购买 | 修页面信任、规格、价格、Review、竞品对比 |
| 退货/差评恶化 | 产品事实或页面承诺不匹配 | 修产品、说明书、页面承诺、包装 |

## 广告搜索词动作

不要只用 ACOS 决定搜索词动作。

原则：

- 高相关、有点击无订单：先检查页面、价格、Review、样本量和归因窗口，不要急着否掉。
- 无关或属性冲突词：尽快否定 exact/phrase 或隔离。
- 稳定转化词：从 broad/phrase/auto 迁移到 exact，但要控制 bid 和预算。
- 稳定转化 ASIN：考虑 Product Targeting 或防守结构。
- SQP/自然词中出现赢家：评估是否进入 exact、页面文案和 Store 路径。

数据置信度：

- 低置信：样本小、仍在归因延迟内、库存/价格/页面状态异常。
- 中置信：点击和订单足够看方向，且没有明显 setup 问题。
- 高置信：跨周期重复出现，页面/价格/库存稳定，样本足够。

## 周度经营看板

最少包含：

- 结果概览：销售额、销量、广告花费、ACOS/TACOS、毛利。
- 库存/现金灯：绿/黄/红。
- 页面转化：CTR、CVR、coupon 核销、Review、Q&A、退货。
- 广告：搜索词、ASIN、bid、预算、placement、迁移、否词。
- 自然流量：排名、SQP/查询信号、自然单。
- 竞品：价格、Review、广告、视觉、排名变化。
- 价格/coupon 实验：假设、动作、窗口、结果。
- 下周动作：负责人、期限、指标、回滚条件。

## 动作优先级

按下面顺序：

1. 修硬错误：Listing 状态、价格、库存、coupon、广告未启用、变体异常。
2. 修流量相关性。
3. 修页面和 offer 转化。
4. 修价格/coupon 和毛利。
5. 修广告结构。
6. 库存和现金门控通过后再放大预算。

## Go / Pivot / Kill

不要在检查这些内容前直接说“产品失败”：

- setup
- target/相关性
- 页面/视觉/文案信任
- 价格/offer/coupon
- 库存/现金
- Review/退货/产品事实

决策类型：

- Go：模型有效，门控支持放量。
- Fix：问题明确，可通过页面、广告、价格或运营修复。
- Hold：证据不足，或现金/库存阻塞。
- Pivot target：人群、关键词或 ASIN 战场错误。
- Pivot page：产品可能成立，但页面承诺/视觉/文案不成立。
- Pivot price：经济性或价格带错位。
- Pivot product：产品事实无法满足关键需求。
- Kill：触发预设停止条件，停止并沉淀反向学习。

反向学习问题：

- 哪个关键词误导了我们？
- 哪个竞品假设错了？
- 哪个用户画像不准确？
- 哪个产品参数没承接？
- 哪个页面承诺过强？
- 哪个广告战场不可赢？
- 哪个成本/现金假设过于乐观？
