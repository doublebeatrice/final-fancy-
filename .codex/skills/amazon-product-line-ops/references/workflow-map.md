# 全链路流程图

当用户要求全链路计划、学习路径、章节地图、产品上线顺序或“下一步该做什么”时，读取本文件。

## 总体链路

```text
D-60 到 D0：搭建可上线系统
定方向 -> 市场雷达 -> 机会节点 -> 首个 SKU 角色
-> 5D 词库 / 竞品 / VOC -> 产品定义与 RFQ
-> 定价/coupon/预算 -> 文案/视觉/包装 -> 广告架构 -> Day 0 检查

D0 到 D90：验证并经营系统
上线设置检查 -> 流量相关性 -> 页面转化 -> 价格/coupon/CPA
-> Review/VOC 反馈 -> 库存/现金 -> scale/fix/hold/pivot/kill
```

## 阶段逻辑

### 1. 产品线方向

目标：确定长期经营边界，不是找一个热卖 SKU。

必须回答：

- 服务谁？
- 解决什么问题？
- 靠什么能力赢？
- 不碰哪些机会？
- 首个 SKU 承担什么角色？

### 2. 市场雷达

不要只问“市场大不大”，要问“新品能不能进入、能不能转化、能不能盈利”。

检查：

- 需求与搜索入口
- 非品牌词和长尾机会
- 竞品页面、视觉、教育、包装是否低效
- 价格带与毛利空间
- 广告成本与流量竞争
- 团队能力与现金压力

### 3. 节点与商品集

节点不是关键词。节点是需求、产品形态、竞争环境、价格带和可运营空间的交汇点。

候选节点漏斗：

```text
需求存在 -> 流量可进 -> 竞品可打 -> 产品可做 -> 经济可算
```

### 4. 证据资产

产品定义前，至少建立：

- ASIN 证据池
- 5D 词库
- 竞品库
- Review/Q&A/VOC 映射
- 价格与 coupon 证据
- 供应链与合规假设

### 5. 产品与页面资产

产品定义先于文案和视觉。标题、五点、主图、附图、A+、视频、包装、说明书必须表达同一组产品事实和边界。

### 6. 上线与 Day 0-D90 经营

Day 0 是真实流量测试，不是发布截止日期。

阶段门控：

- D0-D7：检查 setup、曝光、CTR、CPC、搜索词相关性；不要用当天 ACOS 激进决策。
- D8-D30：看 CVR、CPA、coupon 领取/核销、Review/Q&A、页面与 offer 修复。
- D31-D60：合并广告、SQP/自然流量、TACOS、排名、库存和现金，判断 scale/fix/hold。
- D61-D90：测试 coupon 退坡、防守核心词/ASIN、评估促销、Brand Store 路径和产品线扩展。

## 需要先回头补课的信号

- 市场结论只有“搜索量大”。
- 节点只是一个关键词或一个热卖 ASIN。
- 产品定义只有形容词，没有可测参数。
- 关键词没有页面/广告/否词路由。
- 文案和图片承诺了产品、包装或说明书无法证明的内容。
- CVR、库存、现金或页面信任没解决就开始放大广告。
- 周会只有数据，没有负责人、动作、复查日期和回滚条件。
