# 广告优化与 ACOS 深度诊断手册

当用户问广告、PPC、ACOS、CPC、CTR、CVR、CPA、TACOS、搜索词、否词、预算、bid、placement、ASIN 投放、广告报表诊断时，读取本文件。

核心原则：ACOS 是结果，不是原因。ACOS 高不能直接等于“砍广告”。必须先判断数据置信度、流量相关性、点击吸引、页面转化、价格/coupon、CPC、毛利、库存、现金和自然流量回流。

## 1. 广告底层逻辑

### 1.1 广告不是买词

广告的真实作用：

- 选择战场：决定进入哪个关键词、ASIN、类目、价格带、竞品页。
- 验证流量：验证用户是否愿意点、页面是否能转化、价格是否能承接。
- 分配预算：把钱从低置信、低相关、不可承受的流量，转移到高相关、可转化、可复利的流量。
- 训练资产：把搜索词、ASIN、CTR/CVR、SQP/自然数据回流到词库、页面、价格和产品定义。

### 1.2 广告不能补救弱产品

如果产品定义、价格、主图、Review、页面信任、库存、现金有硬伤，广告只会放大问题。广告优化前先检查：

| 前置项 | 检查问题 |
|---|---|
| 产品 | 产品是否承接关键词和用户任务 |
| 页面 | 标题、主图、五点、A+、FAQ 是否解释清楚 |
| Offer | sale price、coupon、配送、库存是否正常 |
| Review | 评分、评论数、差评是否形成明显劣势 |
| 毛利 | CPA/CPC 是否有可承受边界 |
| 库存现金 | 是否能承接放量和补货 |

## 2. 数据准备

### 2.1 最好提供的数据

| 数据 | 关键字段 | 用途 |
|---|---|---|
| Campaign 报表 | campaign、ad group、target、match、budget、bid、placement、状态 | 看结构和设置 |
| Search Term 报表 | customer search term、targeting、impressions、clicks、spend、sales、orders、ACOS、CPC | 做搜索词动作 |
| Targeting 报表 | keyword/ASIN、match、bid、impressions、clicks、orders、sales、spend | 看词/ASIN 表现 |
| Advertised Product 报表 | SKU/ASIN、花费、销售、订单 | 看 SKU 层面承接 |
| Placement 报表 | top of search、product pages、rest of search | 看加价和 CPC 风险 |
| 价格/coupon 记录 | sale price、coupon、领取、核销、修改日期 | 看 offer 变化 |
| Business Reports/SQP | sessions、unit session %、查询、自然点击/购买 | 看自然回流 |
| 库存/现金 | 可售天数、在途、补货、现金预算 | 判断能否放量 |

### 2.2 数据置信度

| 置信度 | 表现 | 动作 |
|---|---|---|
| 低 | 刚上线、点击少、仍在归因窗口、价格/页面刚改、库存异常 | 不做激进砍词或放量 |
| 中 | 点击和订单能看方向，但周期短或变量多 | 小幅调 bid、隔离测试、修页面 |
| 高 | 跨周期重复出现，变量稳定，样本足够 | 迁移、否词、加预算、降预算 |

注意：不同类目、价格带、客单价、CVR 差异很大，不要套固定点击阈值。用账户历史、同类 campaign、毛利边界和观察周期做校准。

## 3. ACOS 高时先问 10 个问题

| 问题 | 看什么 | 可能结论 |
|---|---|---|
| 数据够不够？ | 点击、订单、归因窗口、修改记录 | 可能只是低样本或归因延迟 |
| 流量相关吗？ | 搜索词、ASIN、词义、属性是否冲突 | 不相关就否词/隔离 |
| CTR 怎么样？ | 曝光到点击 | 主图、标题、价格、coupon、Review、相关性问题 |
| CVR 怎么样？ | 点击到订单 | 页面、价格、Review、A+、规格、信任问题 |
| CPC 是否过高？ | CPC、bid、placement、竞价环境 | 战场太贵或出价叠加失控 |
| CPA 是否超过边界？ | CPA vs Breakeven CPA | 毛利无法承受或 CVR/CPC 要修 |
| TACOS 怎么变？ | 广告花费/总销售额 | 可能广告带动自然，也可能整体亏损扩大 |
| coupon 是否有效？ | 领取率、核销率、CVR、毛利 | 优惠吸引但未转化，或利润被吃掉 |
| 库存现金允许吗？ | 可售天数、补货、现金灯 | 库存/现金红灯时不能放大 |
| 自然数据回流吗？ | SQP、自然排名、自然单、品牌搜索 | 判断广告是否带来复利 |

## 4. 漏斗诊断

### 4.1 曝光低

可能原因：

- Listing 未正常上架、Buy Box/库存/配送异常。
- 关键词未索引或页面相关性不足。
- bid 太低、预算太小、广告状态错误。
- 定向过窄或匹配方式不适合探索。
- 产品价格/Review 竞争力太弱，系统不给量。

动作：

- 先查 setup：状态、库存、价格、Buy Box、预算、bid、广告组、否词是否误伤。
- 核心高相关词曝光低：检查页面是否承接该词，再小幅提高 bid 或用 Phrase/Exact 测。
- 低相关词曝光低：不用追求曝光。

### 4.2 曝光高但 CTR 低

说明用户看到了但不愿意点。先看：

- 搜索词和产品是否相关。
- 主图是否一眼识别品类、规格、套装、差异。
- 标题是否说清产品身份。
- 价格/coupon 是否与竞品有明显劣势。
- Review 数量、评分是否被竞品压制。
- 广告位是否不适合该产品。

动作：

- 不相关流量：否词或隔离。
- 相关但 CTR 低：优先修主图、标题、价格/coupon、Review 信任。
- Top of Search CTR 低且 CPC 贵：谨慎降低 placement 或 bid。

### 4.3 CTR 可以但 CVR 低

说明用户愿意点，但页面或 offer 没有完成转化。先看：

- 五点是否解释机制、规格、场景、边界。
- 附图/A+ 是否回答用户顾虑。
- 价格和 coupon 是否有说服力。
- Review、Q&A、退货、差评是否形成阻力。
- 产品实际形态是否与搜索词意图匹配。
- 竞品页面是否明显更强。

动作：

- 修页面：五点、附图、A+、FAQ、对比图、使用步骤。
- 修 offer：sale price/coupon 组合，但一次只改一个关键变量。
- 修词：高相关词保留观察，低相关/错意图词隔离或否定。

### 4.4 CPC 高

先判断是“值得贵”还是“战场错”。

检查：

- bid 是否超过 Breakeven CPC。
- placement 加价是否叠加导致真实 CPC 失控。
- 是否在硬拼头部大词。
- 是否有长尾 exact、ASIN PT、类目窄定向替代。
- 词的 CVR 是否足够支撑高 CPC。

动作：

- 高 CPC + 高 CVR + CPA 可承受：可保留或独立预算。
- 高 CPC + CVR 低：降 bid、转长尾/PT、修页面。
- 高 CPC + 低相关：否定或停止。

### 4.5 CPA 高

CPA = 广告花费 / 订单。CPA 高通常来自：

- CPC 太高。
- CVR 太低。
- 客单价低或毛利薄。
- coupon/促销吃掉贡献毛利。

动作：

- 先算 Breakeven CPA。
- 如果 CPA 超边界但 CVR 有改善空间，先修页面/offer。
- 如果 CPA 超边界且 CPC 由大词竞争造成，缩窄战场。
- 如果 CPA 超边界且毛利模型不成立，进入价格、产品或 No-Go 讨论。

## 5. ACOS 高的情景动作表

| 情景 | 不能直接做什么 | 应该检查 | 建议动作 |
|---|---|---|---|
| ACOS 高 + 点击少 | 不能立刻否词 | 样本量、归因窗口、是否刚改页面/价格 | 观察或小幅调 bid |
| ACOS 高 + 低相关词花费 | 不能继续等奇迹 | 词义、属性、场景、产品形态 | 否定 exact/phrase 或隔离 |
| ACOS 高 + CTR 低 | 不能只降预算 | 主图、标题、价格、coupon、Review、广告位 | 修搜索页吸引力，清理弱定向 |
| ACOS 高 + CVR 低 | 不能只砍 bid | 页面、A+、FAQ、价格、Review、产品匹配 | 修页面/offer，保留高相关词观察 |
| ACOS 高 + CPC 高 | 不能只加预算抢位 | bid、placement、战场竞争、Breakeven CPC | 控 bid，转长尾/PT，拆预算池 |
| ACOS 高 + TACOS 下降 | 不能只看广告亏 | 自然单、排名、SQP、毛利、现金 | 判断是否启动期投资，可保留受控预算 |
| ACOS 高 + TACOS 上升 | 不能继续放量 | 总销售、毛利、自然回流、广告结构 | 降低探索浪费，保留赢家 |
| ACOS 高 + coupon 领取高核销低 | 不能继续加 coupon | 页面信任、价格、规格、Review、竞品对比 | 修页面或调 offer，不盲目加折扣 |
| ACOS 高 + 库存黄/红 | 不能扩预算 | 可售天数、在途、补货现金 | 控量、防守核心词，优先库存 |
| ACOS 高 + Review/退货恶化 | 不能继续拉流量 | 差评原因、页面承诺、产品事实 | 修产品/页面/说明书，降低承诺 |

## 6. 搜索词动作规则

### 6.1 先分四类

| 类型 | 判断 | 动作 |
|---|---|---|
| 高相关 + 有订单 + CPA 可承受 | 赢家候选 | 迁移 Exact，独立预算，控制 bid |
| 高相关 + 有点击无订单 | 可能样本不足或页面/价格弱 | 查 CVR、页面、Review、价格，不急否 |
| 中相关 + 成本可控 | 探索候选 | 低预算观察，可能进 Phrase/Broad |
| 低相关/冲突 + 反复花费 | 浪费或误导 | 否定 exact/phrase，必要时否定 phrase |

### 6.2 否词不要误伤

- 否定 exact：只排除这个具体搜索词，适合单个无关词。
- 否定 phrase：排除包含某个词组的一批搜索词，适合明确冲突词根。
- 品牌词：不要写进 Listing。广告是否使用要看合规边界、站点规则和风险承受。
- 属性冲突词：如果产品没有该规格/材质/兼容，优先否定或隔离。
- 高搜索低相关词：不要因为搜索量大就保留。

### 6.3 迁移规则

| 来源 | 触发条件 | 迁移 |
|---|---|---|
| Auto | 搜索词高相关、有订单或强互动 | Phrase/Exact |
| Broad | 搜索词稳定出现且相关 | Phrase/Exact |
| Phrase | 具体长尾表现好 | Exact |
| Category | 某类 ASIN 表现好 | ASIN PT 或更窄类目 |
| SQP/自然词 | 自然点击/购买信号上升 | 页面强化 + Exact 测试 |
| 竞品页 | ASIN 转化好 | 独立 PT campaign |

迁移后，原探索 campaign 可保留，但要用否词避免重复抢预算。

## 7. 预算池与 campaign 结构

每个 campaign 只能有一个主要任务。建议分池：

| 预算池 | 目的 | 控制点 |
|---|---|---|
| 探索池 | 找词/找 ASIN | 小预算、宽匹配、严查浪费 |
| 验证池 | 验证中高相关目标 | Phrase/Exact/PT，观察 CPA/CVR |
| 收割池 | 放大赢家 | 独立预算，保护日预算 |
| 防守池 | 防品牌词、核心 ASIN、老品 | 不和探索混钱 |
| 修复池 | 验证页面/价格改动 | 小预算、短窗口、动作日志 |

风险：

- 探索和收割混在一起，会让赢家没预算。
- Broad、Phrase、Exact 混在一个广告组，会让数据难以解释。
- placement 加价没有上限意识，会让真实 CPC 超边界。
- 没有操作日志，无法知道结果来自哪个动作。

## 8. bid 与 placement 调整

### 8.1 调 bid 前先看边界

| 情况 | 动作 |
|---|---|
| CPC 低于 Breakeven CPC，CVR 好 | 可保留或小幅加 bid |
| CPC 接近边界，CVR 不稳定 | 稳定观察，不激进 |
| CPC 高于边界，CVR 低 | 降 bid 或换战场 |
| CPC 高但带动自然且现金允许 | 保留受控预算，跟踪 TACOS |

### 8.2 调整节奏

- 不要一天多次大幅调 bid。
- 价格、coupon、主图、页面和 bid 不要同一时间大改。
- 每次调整写清：原因、目标、调整幅度、观察窗口、回滚条件。
- 库存/现金黄灯时，优先保核心词和赢家，压缩探索。

## 9. 广告与页面联动

| 广告信号 | 页面动作 |
|---|---|
| 高相关词 CTR 低 | 主图、标题、价格/coupon、Review 竞争力 |
| 高相关词 CTR 高 CVR 低 | 五点、附图、A+、FAQ、价格、信任 |
| 属性词点击多无单 | 规格/兼容/材质是否讲清 |
| 场景词点击多无单 | 场景图、A+教育、用户画像是否错位 |
| 痛点词点击多无单 | 是否承诺过强、机制证据不足 |
| ASIN PT 点击多无单 | 对方价格/Review/页面是否太强，自己页面是否不承接 |

## 10. 广告与 coupon/价格联动

判断 coupon 不能只看“有没有销量”。

| 信号 | 可能含义 | 动作 |
|---|---|---|
| coupon 领取高、核销低 | 用户感兴趣但不信任或价格仍不够 | 修页面/价格/Review，不盲目加折扣 |
| coupon 核销高、毛利负 | 折扣带来订单但模型不可持续 | 调低 coupon 或重算价格 |
| CVR 上升、CPA 下降 | offer 改善有效 | 继续观察库存现金，再考虑放量 |
| CVR 不变、毛利下降 | coupon 无效 | 停止或换测试变量 |
| coupon 后 ACOS 降但 TACOS 升 | 广告销售好看但总经营压力变大 | 看总利润和自然回流 |

## 11. 广告与自然流量/SQP 联动

ACOS 高但不一定坏，关键看是否形成自然回流：

- 核心查询自然点击是否增长。
- 自然购买份额是否增长。
- 关键词自然排名是否改善。
- 总销售是否增长，而 TACOS 是否下降或受控。
- Review、评分、退货是否稳定。
- 库存和现金是否允许继续投资。

如果广告花费上升，但自然没有回流、TACOS 上升、毛利恶化，要收缩或重构战场。

## 12. 广告复盘节奏

| 节奏 | 重点 |
|---|---|
| 每日 | setup、预算是否耗尽、异常花费、库存/价格/coupon 状态 |
| 48-72 小时 | 新 campaign 初步流量相关性、CTR、CPC |
| 每周 | 搜索词迁移、否词、预算池调整、页面/价格联动 |
| 每两周 | 词库回流、ASIN PT、placement、自然数据联动 |
| 每月 | campaign 审计、浪费清理、赢家放大、失败战场复盘 |

## 14. 常见错误

- 只看 ACOS，不看 CTR、CVR、CPC、CPA、TACOS。
- 高相关词点击无单就立刻否掉。
- 低相关词因为偶尔出单就继续放量。
- Broad、Phrase、Exact、PT 混在一个预算池。
- 赢家词没有独立预算。
- 看到 coupon 领取高就加大 coupon，不看核销和毛利。
- 库存不足还继续扩大广告。
- 广告动作没有日志，无法复盘。
- 价格、主图、coupon、bid 同时改，导致无法判断原因。
