# 上架执行 SOP

当用户问“这个产品怎么上架”“上架前要准备什么”“从现在到上线怎么做”“Day 0 后怎么跑”时，读取本文件。

## 一、上架不是填 Listing

上架的目标不是把页面发布出去，而是让产品、价格、页面、广告、库存、现金、信任资产能承受真实流量检验。

## 二、D-60 到 D0 总路线

| 时间 | 核心目标 | 必须完成 |
|---|---|---|
| D-60 到 D-45 | 确认方向和市场 | 方向卡、市场雷达、候选节点、No-Go 清单 |
| D-44 到 D-30 | 确认商品集和首个 SKU | ASIN 池、节点评分、商品集、首个 SKU 角色、产品 Brief |
| D-29 到 D-15 | 完成产品定义和供应验证 | 9 字段产品定义、RFQ、样品、成本、合规、包装要求 |
| D-14 到 D-7 | 完成页面和广告准备 | 词库、竞品库、VOC、标题五点、主图附图、A+、广告架构、预算模型 |
| D-6 到 D0 | 完成上线检查 | Listing、价格/coupon、库存、广告、Vine/Creator、监控表、风险红线 |

如果某阶段输出不合格，不要为了赶日期强行进入下一阶段。

## 三、上架前九包

| 包 | 内容 | 检查点 |
|---|---|---|
| 1. 市场包 | 市场雷达、节点结论、竞品格局 | 是否有结构性低效 |
| 2. 产品包 | 产品定义、SKU 角色、RFQ、样品反馈 | 供应商是否能做出定义 |
| 3. 词库包 | 5D 词库、词根、页面/广告/否词路由 | 是否只堆词 |
| 4. 竞品包 | 直接/替代/学习/广告竞品 | 每个竞品是否反哺动作 |
| 5. VOC 包 | Review/Q&A/退货/Creator 用户语言 | 是否转成产品和页面动作 |
| 6. 定价包 | sale price、coupon、毛利、Breakeven CPA/CPC | 是否能承受广告和补货 |
| 7. 页面包 | 标题、五点、A+、后台词、FAQ | 是否承接产品定义 |
| 8. 视觉包装包 | 主图、附图、视频、包装、说明书 | 是否一致、清楚、合规 |
| 9. 广告上线包 | campaign 架构、预算、bid、PT、否词、日志 | 是否能验证流量战场 |

## 四、Day 0 检查清单

| 检查项 | 通过标准 |
|---|---|
| Listing 状态 | 前台可见，标题/五点/A+/图片/属性正确 |
| Featured Offer | 可购买、价格正常、配送正常 |
| 库存 | FBA 可售，补货计划和安全库存明确 |
| 价格 | sale price、coupon、到手价与毛利边界一致 |
| 广告 | campaign 已启用，预算、bid、匹配、placement、命名正确 |
| 词库 | 核心词、属性词、长尾词、否词池已准备 |
| 风险 | Review、Vine、coupon、图片、宣称、类目规则已核查 |
| 日监控 | 负责人、监控指标、异常升级、操作日志已准备 |

Day 0 不能有这些问题：

- 产品核心参数还没定。
- 标题和图片表达不一致。
- coupon 没算进毛利。
- 广告开了但否词和预算池没准备。
- 库存不足还准备放量。
- 合规规则没有按当前后台复核。

## 五、上线后 D0-D90 运营

### D0-D7：排错和相关性

目标：确认系统正常，流量相关。

看：

- Listing 是否正常展示。
- Featured Offer、价格、coupon、库存是否异常。
- 广告是否消耗。
- CTR、CPC、搜索词是否相关。

不要：

- 用当天 ACOS 关停核心词。
- 同时大改主图、价格、bid、coupon。

### D8-D30：转化修复

目标：确认页面和 offer 能否承接流量。

看：

- CVR、CPA。
- coupon 领取率和核销率。
- Review、Q&A、Vine/Creator 反馈。
- 主图/A+/五点是否需要修。

动作：

- 修页面信任。
- 修规格/兼容/使用步骤。
- 调整价格/coupon，但要记录实验。
- 把稳定相关词迁移到更精确结构。

### D31-D60：判断是否放量

目标：判断模型能否扩大。

看：

- TACOS。
- 自然单和自然词。
- SQP/查询信号。
- 库存和现金。
- 核心词/ASIN 表现。

动作：

- 放大赢家词/ASIN。
- 控制无效战场。
- 处理库存和补货。
- 判断 Scale/Fix/Hold。

### D61-D90：防守和扩展

目标：防守核心战场，判断产品线扩展。

看：

- coupon 是否能退坡。
- 核心词/ASIN 是否能防守。
- LD/BD 是否适合。
- Store 路径是否承接。
- 是否出现关联 SKU 机会。

动作：

- 测试 coupon 退坡。
- 防守核心词和核心 ASIN。
- 评估促销。
- 进入关联产品线地图。

## 六、上线动作优先级

1. 先修硬错误：Listing、价格、coupon、库存、广告状态。
2. 再修流量相关性：关键词、ASIN、匹配方式、否词。
3. 再修页面转化：主图、标题、五点、A+、FAQ、Review 信任。
4. 再修 offer：价格、coupon、配送、变体。
5. 再修广告结构：预算、bid、placement、迁移。
6. 最后才放大预算。

## 七、上线后复盘输出

每次复盘必须给：

| 字段 | 内容 |
|---|---|
| 当前阶段 | D0-D7 / D8-D30 / D31-D60 / D61-D90 |
| 当前结论 | Go / Fix / Hold / Pivot / Kill |
| 最大问题 | setup / target / page / price / inventory / product |
| 证据 | 指标、搜索词、Review、竞品、库存、现金 |
| 动作 | 做什么 |
| 负责人 | 谁做 |
| 复查日期 | 什么时候看结果 |
| 回滚条件 | 什么情况下撤回动作 |
