# 分析前提与填表模板

当用户问“我要给你什么资料你才能分析”“模板怎么填”“帮我整理输入信息”时，读取本文件。

目标：在正式分析产品前，先收集足够的数据，让后续判断不是凭感觉，而是能围绕产品、市场、竞品、词库、广告、成本、库存和合规做完整诊断。

优先采用“卖家精灵导出数据 + 产品图/链接 + 少量人工确认”的方式，减少手填。

## 一、数据完整度分级

| 等级 | 可以做什么 | 最低资料 |
|---|---|---|
| L1 初步判断 | 判断产品画像、明显风险、初步机会 | 产品信息、站点、目标价格、3-5 个竞品、核心词 |
| L2 可验证分析 | 判断市场节点、商品集、词库方向、页面策略 | L1 + 20-50 个关键词、10-20 个竞品、成本和价格 |
| L3 上架计划 | 做 D-60 到 D0 上架 SOP、Listing/视觉/广告准备 | L2 + 产品定义、样品/供应、图片、包装、合规、预算 |
| L4 投放/复盘 | 检查广告、搜索词、coupon、D0-D90 动作 | L3 + 广告报表、搜索词报表、CPC、CVR、库存、Review |

如果资料不足，仍可先做初步诊断，但必须标注证据缺口。

## 二、推荐输入方式：少手填版本

用户可以直接提供：

1. 产品图片、产品链接或样品描述。
2. 卖家精灵导出的市场/竞品/关键词/ASIN 反查/CPC/Review 数据。
3. 少量人工信息：目标站点、目标售价、成本、供应情况、是否已有品牌和合规风险。

拿到数据后，先自动清洗并生成：

- 产品类型：标品 / 非标品 / 半标品。
- 直接竞品候选。
- 剔除竞品及剔除原因。
- 关键词分组和疑似否词。
- 广告 CPC 和预算风险。
- 需要人工确认的问题。

## 三、必填资料

### 1. 产品基础信息

| 字段 | 为什么需要 |
|---|---|
| 产品名称/类目 | 判断商品集和竞品范围 |
| 目标站点 | 不同站点价格、政策、合规、广告成本不同 |
| 产品图片/链接/样品描述 | 判断产品形态、视觉表达和差异点 |
| 规格参数 | 决定页面承诺、RFQ、关键词和竞品对比 |
| 目标用户/使用场景 | 决定市场节点、VOC、文案和视觉主线 |
| 目标售价/到手价 | 判断价格带和毛利空间 |
| 产品成本/MOQ/交期 | 判断供应和现金压力 |
| 是否已有品牌/店铺阶段 | 决定广告和信任建设难度 |

### 2. 市场分析数据

| 字段 | 为什么需要 |
|---|---|
| 核心关键词 | 判断主入口 |
| 属性词/场景词/痛点词 | 判断长尾机会和节点 |
| ABA/SFR/搜索量 | 判断需求强弱和入口结构 |
| 目标价格带 | 判断进入空间 |
| 主要类目/小类排名 | 判断竞争位置 |
| 市场季节性 | 判断上线节奏和库存 |
| 结构性低效观察 | 判断有没有可打入口 |

### 3. 竞品分析数据

| 字段 | 为什么需要 |
|---|---|
| ASIN | 作为竞品证据索引 |
| 品牌/标题 | 判断定位和关键词 |
| 价格/coupon | 判断价格带和促销结构 |
| Review 数/评分 | 判断信任壁垒 |
| 主图/附图/A+特点 | 判断视觉和页面弱点 |
| 差评痛点 | 翻译成产品、页面、包装动作 |
| 规格/套装/材质 | 判断商品集边界 |
| 广告位置 | 判断可打战场 |

### 4. 关键词数据

| 字段 | 为什么需要 |
|---|---|
| keyword | 原始词 |
| 搜索量/ABA/SFR | 判断流量级别 |
| 相关性 | 防止高流量低相关词带偏 |
| 词型 | 品类、属性、场景、痛点、品牌、噪音 |
| 预估 CPC | 判断广告成本 |
| 竞品覆盖情况 | 判断页面和广告竞争 |
| 页面路由 | 标题、五点、A+、后台词、图片、FAQ |
| 广告路由 | Auto、Broad、Phrase、Exact、PT、否词 |

### 5. 广告与 CPC 数据

| 字段 | 为什么需要 |
|---|---|
| 目标 CPC 或建议竞价 | 判断流量成本 |
| 竞品广告位置 | 判断战场竞争 |
| 目标 CVR | 反推 Breakeven CPC |
| 目标 CPA | 判断获客成本上限 |
| 预算 | 判断冷启动能跑多少样本 |
| 匹配方式 | 判断探索/验证/收割是否分层 |
| 搜索词表现 | 判断迁移、否词、降 bid、保留 |

### 6. 成本、库存和现金

| 字段 | 为什么需要 |
|---|---|
| 产品成本 | 贡献毛利基础 |
| 头程/关税/包装 | 到手成本 |
| Amazon referral fee/FBA 费 | 平台成本 |
| coupon/Deal 成本 | 促销压力 |
| 预估退货率 | 真实毛利 |
| 首批数量/补货周期 | 库存风险 |
| 可用广告预算/补货现金 | 是否能承接放量 |

### 7. 合规与风险

| 字段 | 为什么需要 |
|---|---|
| 是否涉及认证 | 类目准入和 Listing 风险 |
| 是否涉及儿童/食品/美妆/电池/医疗等 | 高风险类目 |
| 是否有专利/商标风险 | 侵权风险 |
| 图片/文案是否有功效宣称 | 页面合规风险 |
| Vine/coupon/Review 计划 | 需要按当前规则核查 |

## 四、Excel 模板 Sheet 结构

建议使用工作簿 `亚马逊产品分析输入模板.xlsx`，包含：

1. `01_填写说明`
2. `02_产品基础信息`
3. `03_成本定价库存`
4. `04_市场分析`
5. `05_竞品分析`
6. `06_关键词词库`
7. `07_广告CPC数据`
8. `08_Listing视觉包装`
9. `09_合规风险`
10. `10_分析输出`

## 五、卖家精灵导出数据要求

如果提供卖家精灵文件，尽量包含：

| 文件/数据 | 用途 |
|---|---|
| 商品/竞品导出 | 识别竞品池、价格带、Review 壁垒 |
| 关键词挖掘/拓展 | 建立 5D 词库 |
| ASIN 反查/流量词 | 判断竞品流量入口和广告战场 |
| CPC/广告建议竞价 | 计算 Breakeven CPC 和预算压力 |
| Review/差评导出 | 提取 VOC 和产品/页面改进点 |

字段名不固定，但最好包含 ASIN、标题、品牌、图片、价格、coupon、月销量、月销售额、Review、评分、BSR、keyword、搜索量/ABA/SFR、CPC、广告位、自然/广告排名、评论内容、抓取日期。

## 六、填表质量要求

- 所有 ASIN、关键词、价格、Review、CPC 数据尽量带日期。
- 不要只填结论，要填证据链接、截图说明或来源。
- 不确定的字段可以填 `未知`，不要乱编。
- 如果是预估值，标注 `预估`。
- 如果来自第三方工具，标注工具名和抓取日期。
- 如果涉及平台规则，标注是否已核对当前 Seller Central / Amazon Ads 后台。

## 七、分析时如何使用这些数据

拿到填表后，按下面顺序分析：

1. 先看产品图/链接，判断产品形态、标品/非标品和关键属性。
2. 再看产品基础和成本，判断产品是否有基本经济性。
3. 再看市场和竞品，判断节点、商品集和结构性低效。
4. 再按标品/非标品逻辑筛相似竞品，不只按销量筛。
5. 再看关键词，判断页面主线和广告战场。
6. 再看广告 CPC，计算 CPA/CPC 边界和预算能否跑出样本。
7. 再看 Listing、视觉、包装，判断能否承接用户决策。
8. 最后看合规、库存和现金，决定 Go / Validate / Hold / No-Go。
