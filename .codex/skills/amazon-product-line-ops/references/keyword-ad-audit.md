# 词库与广告审计

当用户提供关键词表、广告结构、搜索词报表、Listing 词、广告计划，或要求“帮我检查词库/广告”时，读取本文件。

目标：检查词库是否能服务页面和广告，广告是否能验证正确战场，而不是只看 ACOS。

## 一、词库审计

### 1. 词库最低要求

一张合格词库必须能回答：

1. 这个词和产品强相关、中相关、弱相关、冲突还是无关？
2. 它是品类词、属性词、场景词、痛点词、品牌词还是噪音词？
3. 它有没有购买意图？
4. 它应该进标题、五点、A+、后台词、图片、FAQ、广告还是否词？
5. 它是否能被产品事实承接？
6. 它的 CPC/CPA 是否可能被毛利承受？

### 2. 词库检查表

| 检查项 | 合格标准 | 风险 |
|---|---|---|
| 相关性 | 重要词有高/中/低/冲突分类 | 高流量低相关词带偏页面和广告 |
| 词型 | 品类、属性、场景、痛点、品牌、噪音已分类 | 所有词混在一起 |
| 词根 | 词根和变体已归类 | 重复投放、否词误伤 |
| 页面路由 | 标题/五点/A+/后台词/图片/FAQ 有分配 | Listing 堆词 |
| 广告路由 | Auto/Broad/Phrase/Exact/PT/防守/测试明确 | 广告结构混乱 |
| 否词路由 | 无关、冲突、品牌、误导词有动作 | 浪费预算 |
| 证据 | 每个核心词有来源 | 凭感觉选词 |
| 毛利边界 | 高 CPC 词有 CPA 容忍判断 | 词能出单但亏钱 |

### 3. 词库分层

| 层级 | 定义 | 用法 |
|---|---|---|
| 核心高相关词 | 产品身份和购买意图都强 | 标题前部、Exact、主图/A+核心表达 |
| 属性词 | 材质、规格、尺寸、颜色、容量、兼容 | 五点、附图、Exact/Phrase |
| 场景词 | 使用场景、节日、地点、人群 | 附图、A+、Phrase/Broad |
| 痛点词 | 用户问题和需求 | 五点、A+、FAQ、视频 |
| 竞品词/ASIN | 竞品品牌、ASIN、替代品 | 合规边界内用于 PT/研究，不写入 Listing |
| 噪音词 | 无关、冲突、误导、低意图 | 否词或排除 |

### 4. 词到页面

| 页面位置 | 适合放什么词 |
|---|---|
| 标题 | 高相关、强购买、能定义产品身份的词 |
| 五点 | 属性、痛点、结果、兼容、使用边界 |
| A+ | 教育、对比、场景、步骤、品牌信任 |
| 后台词 | 相关但不适合前台重复的词 |
| 图片 headline | 用户一眼要懂的差异点 |
| FAQ | 容易误解、安装、兼容、尺寸、使用限制 |

## 二、广告架构审计

### 1. 广告不是只开 SP

检查广告是否有不同任务：

| 广告任务 | 目的 | 常见结构 |
|---|---|---|
| 探索 | 找真实搜索词和 ASIN | Auto、Broad、Category |
| 验证 | 验证中高相关词/ASIN | Phrase、Exact、PT |
| 收割 | 放大稳定转化目标 | Exact、强 ASIN PT |
| 防守 | 防守品牌词、核心 ASIN、老品流量 | Brand/ASIN defense |
| 修复 | 检查页面或价格是否承接 | 小预算测试，不盲目扩量 |

### 2. campaign 检查表

| 检查项 | 合格标准 | 风险 |
|---|---|---|
| 命名 | 站点_SKU_目标_匹配_阶段_日期 | 后期无法复盘 |
| 目标 | 每个 campaign 只有一个主要任务 | 探索、收割、防守混在一起 |
| 预算池 | 探索/验证/收割/防守预算分开 | 赢家和测试词抢预算 |
| 匹配方式 | Auto/Broad/Phrase/Exact 分工清楚 | 数据无法判断 |
| PT | ASIN/类目/价格带/Review 差异有逻辑 | 随机打竞品 |
| 否词 | 无关词、冲突词、误导词有处理 | 持续浪费 |
| bid | 与 Breakeven CPC 和阶段目标相关 | 凭感觉出价 |
| placement | 看最大可能 CPC，不只看单项加价 | bid 叠加导致 CPC 失控 |
| 日志 | 每次改动有原因、日期、复查 | 不能回滚 |

## 三、搜索词动作规则

| 搜索词表现 | 判断 | 动作 |
|---|---|---|
| 高相关、有点击无订单 | 可能是样本不足、页面弱、价格弱、Review 弱 | 先看样本和页面，不急否 |
| 高相关、有订单、CPA 可承受 | 赢家候选 | 迁移到 Exact，给独立预算 |
| 高相关、有订单但 CPA 高 | 可能 CPC 高或 CVR 低 | 降 bid、修页面、看毛利 |
| 低相关、反复花费 | 浪费 | 否定 exact/phrase |
| 属性冲突 | 明显误导 | 否定 |
| 品牌词 | 合规边界内研究/广告，不能写入 Listing | 单独管理 |
| ASIN 转化好 | 竞品页可打 | 建 PT 或加预算 |
| ASIN 点击多无单 | 竞品强或页面不承接 | 降 bid、换目标或修页面 |

## 四、广告不能单看 ACOS

同时看：

- CTR：用户是否愿意点。
- CVR：页面是否能转。
- CPC：流量是否太贵。
- CPA：单个订单成本是否在毛利边界内。
- TACOS：广告是否带动整体自然增长。
- coupon 核销率：优惠是否真的促成购买。
- 库存灯：能不能承接放量。
- 现金灯：补货和广告是否抢同一笔钱。
- Review/退货：短期广告是否带来长期风险。

## 六、常见打回

- 词库只有搜索量，没有相关性和路由。
- Listing 标题塞了高流量但产品无法承接的词。
- 广告结构里 Broad、Phrase、Exact 混在同一个 campaign。
- 预算被探索词耗完，赢家词没预算。
- 看到 ACOS 高就砍词，没有看样本量、归因延迟和页面转化。
- coupon 领取高核销低，却只想加大 coupon。
- 库存不足还继续加预算。
- 没有广告操作日志。
