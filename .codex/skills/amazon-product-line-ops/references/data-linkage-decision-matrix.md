# 经营数据联动诊断矩阵

当用户提供一批运营数据、广告数据、关键词数据、竞品数据、价格/coupon 数据、库存现金数据，或问“这个数据说明什么”“指标异常该怎么办”时，读取本文件。

核心原则：单个指标只说明现象，不说明原因。必须把数据放进链路里看：市场 -> 关键词 -> 流量 -> 页面 -> offer -> 订单 -> 毛利 -> 库存现金 -> Review/VOC -> 自然回流。

## 1. 数据联动总图

```text
市场/节点
-> 关键词/ASIN 入口
-> 广告与自然曝光
-> CTR
-> 页面与 offer
-> CVR
-> CPA/ACOS/TACOS
-> 毛利/现金
-> 库存/补货
-> Review/VOC/退货
-> 自然排名/SQP/复购/Store
-> 产品线扩展或 Go/Pivot/Kill
```

看数据时不要问“这个指标好不好”，要问：

1. 它处在链路哪一段？
2. 它的上游变量是什么？
3. 它会影响哪些下游变量？
4. 这次变化是否由我们刚做的动作造成？
5. 数据置信度够不够？
6. 动作会不会伤害库存、现金、Review 或长期自然流量？

## 2. 指标之间的关系

| 指标 | 上游变量 | 下游影响 | 常见误判 |
|---|---|---|---|
| 曝光 | 索引、bid、预算、定向、价格、类目相关性 | 点击、CPC、搜索词数据 | 曝光低就加预算，忽略索引和相关性 |
| CTR | 主图、标题、价格、coupon、Review、广告位、相关性 | CVR、CPC 效率、系统反馈 | CTR 低只改 bid，不修主图/offer |
| CVR | 页面、价格、coupon、Review、A+、FAQ、产品匹配 | CPA、ACOS、自然排名 | CVR 低只砍广告，不修页面 |
| CPC | bid、placement、竞争强度、匹配方式 | CPA、ACOS、预算消耗 | CPC 高就停投，忽略高 CVR 词 |
| CPA | CPC、CVR、订单数 | 毛利、放量边界 | CPA 高不拆原因 |
| ACOS | 广告花费、广告销售额、客单价 | 广告效率判断 | ACOS 高直接砍 |
| TACOS | 广告花费、总销售额、自然单 | 整体经营压力 | 只看 ACOS 不看自然回流 |
| coupon 核销 | 领取、价格吸引、页面信任 | CVR、毛利、库存 | 领取高就以为有效 |
| Review/评分 | 产品事实、包装、说明、用户预期 | CTR、CVR、退货、广告承接 | 只做广告不修产品 |
| 库存灯 | 销速、在途、补货周期 | 广告预算、排名、防守 | 快断货还放量 |
| 现金灯 | 回款、补货、广告、固定成本 | 放量能力、补货能力 | 只看单单毛利不看现金 |

## 3. 异常症状诊断

### 3.1 销售额下降

先拆：

- 曝光是否下降。
- CTR 是否下降。
- CVR 是否下降。
- 客单价是否下降。
- 广告预算是否被限制或耗尽。
- 自然排名/SQP 是否下降。
- 竞品是否降价、加 coupon、换主图、增加广告。
- 库存、Buy Box、配送是否异常。
- Review/评分是否恶化。

动作：

- 如果曝光下降：查广告状态、索引、预算、bid、自然排名。
- 如果 CTR 下降：查主图、价格、coupon、Review、竞品变化。
- 如果 CVR 下降：查页面、offer、Review、Q&A、库存配送。
- 如果自然下降但广告稳定：查排名、SQP、竞品和页面更新。

### 3.2 广告花费上升但订单没上升

可能原因：

- 流量变宽，相关性下降。
- CPC 上升，预算更快耗完。
- CTR 低，广告位或主图不吸引。
- CVR 低，页面或 offer 不承接。
- 竞品降价/加 coupon。
- 搜索词混入无关词。

动作：

- 按搜索词分相关性。
- 对高花费无单词做样本和归因检查。
- 清理低相关词。
- 修 CTR 或 CVR 的上游变量。
- 重新分预算池，保护赢家词。

### 3.3 ACOS 高

不要直接砍广告。先联动：

| 同时出现 | 更可能的问题 | 动作 |
|---|---|---|
| CTR 低 | 搜索页吸引力或相关性 | 修主图/标题/offer，清定向 |
| CVR 低 | 页面/价格/Review/匹配 | 修页面、价格、FAQ、A+ |
| CPC 高 | 战场贵或 bid/placement 失控 | 降 bid、转长尾/PT、控 placement |
| TACOS 下降 | 可能带来自然增长 | 看毛利/现金，受控保留 |
| TACOS 上升 | 整体经营压力变大 | 缩浪费、保护赢家、查自然 |
| coupon 核销低 | 优惠未转化购买 | 修信任和价格结构 |
| 库存红 | 放量会断货 | 控广告，优先补货 |

广告深度动作读取 `advertising-optimization-playbook.md`。

### 3.4 CTR 下降

检查：

- 主图是否被竞品比下去。
- 价格/coupon 是否失去吸引力。
- Review 数量/评分是否低于同屏竞品。
- 广告是否跑到不相关词。
- 标题是否没有说清产品身份。
- 搜索结果页竞争是否变化。

动作：

- 对核心高相关词，优先修主图、标题、offer。
- 对低相关词，否定或隔离。
- 对竞品变化，记录对方价格、coupon、主图、Review、广告位。

### 3.5 CVR 下降

检查：

- 页面是否改动。
- 价格/coupon 是否变化。
- Review/差评/Q&A 是否出现新问题。
- 变体、库存、配送、Buy Box 是否异常。
- 搜索词意图是否变宽。
- 竞品是否有更强 offer。

动作：

- 修页面解释：规格、组件、使用步骤、兼容、边界。
- 修信任：A+、FAQ、视频、说明书。
- 修 offer：sale price/coupon 组合，但一次只动一个变量。
- 修流量：清理错意图搜索词。

### 3.6 coupon 领取高、核销低

含义：用户被优惠吸引，但没有完成购买。

继续看：

- 详情页是否讲清价值。
- 到手价相对竞品是否仍然弱。
- Review/评分是否阻碍。
- 规格、尺寸、兼容、材质是否不清。
- coupon 面额是否吸引了错误人群。

动作：

- 不要直接加大 coupon。
- 先修页面信任和价格结构。
- 对领取高但核销低的词/ASIN，检查对应人群是否错位。

### 3.7 CVR 上升但利润下降

可能原因：

- coupon 太深。
- 广告 CPC 太高。
- sale price 降太多。
- 高退货或高 FBA/头程费用。
- 低价带带来错误用户。

动作：

- 重算贡献毛利。
- 看 CPA 是否超过 Breakeven CPA。
- 测 coupon 退坡。
- 如果转化依赖亏损折扣，不要放量。

### 3.8 自然单增长但广告亏

可能是启动期投资，也可能是虚假繁荣。检查：

- TACOS 是否下降或受控。
- 自然排名/SQP 是否改善。
- 毛利和现金是否能承受。
- Review/退货是否稳定。
- 库存是否能承接。

动作：

- 如果自然回流明确且现金库存允许，可保留受控预算。
- 如果自然没有回流，缩减亏损战场。

### 3.9 库存黄/红

不要继续追求广告规模。

动作：

- 保留核心词和防守词，压缩探索。
- 降低高浪费 campaign。
- 如果即将断货，谨慎处理排名保护和补货节奏。
- 周会必须同时看在途、交期、补货现金。

### 3.10 Review/退货恶化

广告带来的订单如果引发差评，会伤害长期转化。

检查：

- 差评是否集中在产品质量、尺寸、兼容、使用误解、包装破损。
- 页面承诺是否过强。
- 广告搜索词是否吸引了错误场景用户。
- 说明书和包装是否降低误用。

动作：

- 修产品、说明书、包装和页面承诺。
- 对错意图流量否定或隔离。
- 暂停放量，防止差评扩大。

## 4. 数据联动输出模板

```text
1. 数据范围：
   - 文件/日期/站点：
   - 可用字段：
   - 缺失字段：

2. 当前链路位置：
   - 市场/词库/流量/页面/offer/广告/库存/现金/Review/自然：

3. 主要异常：
   - 现象：
   - 数据证据：
   - 置信度：

4. 上游原因排查：
   - 产品/竞品：
   - 关键词/搜索词：
   - 主图/标题：
   - 页面/A+/FAQ：
   - 价格/coupon：
   - 广告结构：
   - 库存/现金：
   - Review/VOC：

5. 下游影响：
   - 对 ACOS/CPA/TACOS：
   - 对自然排名/SQP：
   - 对库存现金：
   - 对 Review/退货：

6. 建议动作：
   动作 / 原因 / 负责人 / 数据窗口 / 成功指标 / 回滚条件

7. 需要人工确认：
```

## 5. 动作优先级

按以下顺序处理：

1. 修硬错误：上架状态、库存、价格、coupon、Buy Box、广告未启用、预算耗尽。
2. 修流量相关性：错词、错 ASIN、错类目、错人群。
3. 修搜索页吸引力：主图、标题、价格、coupon、Review。
4. 修页面转化：五点、附图、A+、FAQ、视频、信任。
5. 修毛利模型：价格、coupon、CPA/CPC、退货。
6. 修广告结构：预算池、match、PT、迁移、否词、placement。
7. 通过库存和现金门控后，再放大。

## 6. 周会联动看板

周会必须把指标连起来，不要只报广告：

| 模块 | 指标 | 必问问题 |
|---|---|---|
| 销售 | 销量、销售额、客单价 | 增长来自广告还是自然 |
| 广告 | 花费、ACOS、CPA、CPC、CTR、CVR | 问题在流量、点击、页面还是成本 |
| 自然 | SQP、排名、自然单 | 广告是否带来自然回流 |
| 页面 | CTR、CVR、Review、Q&A、退货 | 页面承接是否变好 |
| 价格/coupon | 领取、核销、到手价、毛利 | 优惠是否可持续 |
| 竞品 | 价格、Review、主图、广告位 | 竞争环境是否变了 |
| 库存现金 | 可售天数、在途、补货、现金 | 能否承接放量 |
| 动作日志 | 上周改了什么 | 数据变化是否可归因 |

## 7. 不能直接下结论的情况

- 数据仍在归因窗口。
- 样本太少。
- 同时改了多个变量。
- 库存或 Buy Box 异常。
- 价格/coupon 刚改。
- 页面刚大改。
- 竞品突然大促。
- 类目季节性或节日波动。
- 卖家精灵或后台数据日期不一致。

遇到这些情况，输出“低/中置信暂定判断”，不要给强结论。
