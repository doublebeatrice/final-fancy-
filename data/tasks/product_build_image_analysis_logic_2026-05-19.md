# 新品/老品打造图片分析口径

日期：2026-05-19

## 核心原则

新品和老品打造都不能只看标题、广告、关键词、标签或历史备注。那些都是人打出来或系统生成的，可能错、可能过期、也可能只是某次测试留下的痕迹。

打造前必须先看产品图片，判断产品本身是什么、买家一眼看到的是什么、适合什么场景、适合什么人群，再决定广告、关键词、listing 和打法。

## 新品打造

新品不能先从广告结构出发。先看图片和产品形态：

1. 产品是什么：品类、材质、套装内容、数量、尺寸、颜色、风格。
2. 买家为什么买：礼品、装饰、活动用品、实用品、纪念品、感谢品、宗教/职业/人群礼品等。
3. 适合谁：父亲、母亲、老师、护士、牧师、员工、婚礼宾客、教会/VBS、毕业人群等。
4. 适合什么时候买：节日、节点、季节、活动、日常刚需。
5. 图片能不能支撑关键词：如果图片不支撑，就不能只因为关键词看起来有量就强推。
6. 主图和变体图是否清楚表达卖点：数量、图案、文案、使用方式、包装、礼品感。

新品广告和关键词应该从图片确认出的真实场景、人群和用途出发，再结合市场词、竞品和历史承接数据。

## 老品打造

老品不能只看历史广告打过什么词，也不能只看当前 listing 写了什么。老品要先重新看图：

1. 判断历史打法是否打偏：广告名、关键词、标签可能是旧测试，不一定代表产品真实定位。
2. 判断产品是否能换场景承接：同一个产品可能在不同节日、不同人群下有不同流量入口。
3. 判断图片是否支持当前要推的方向：如果图片是 Pastor，就不能硬说是父亲垂直品，但可以判断是否能承接 Father’s Day 的 Christian gifts / gifts for men / appreciation gifts。
4. 判断是否需要 listing 或图片补强：如果产品能承接某个节点，但图片表达弱，后续应考虑改图或补场景图，而不是只改广告。
5. 判断老品是否已经过季或流量错配：有流量不等于该放量，要看图片、产品身份和转化是否匹配。

## 输出要求

以后做新品/老品打造诊断时，必须明确写出图片判断：

- 图片看到的产品本体是什么。
- 图片支撑哪些人群、场景、节日或用途。
- 图片不支撑哪些曾经打过的方向。
- 当前建议是垂直打造、相邻承接、轻测试、收缩，还是需要先补图/listing。

## 和节日判断的关系

节日产品判断、日常新品打造、老品二次打造都用同一个底层逻辑：

先看图片和产品本身，再看流量和市场，再看广告/listing/关键词。
